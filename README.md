\# Digital Signal Processing (DSP) Implementations



\## 📁 Included Modules



\- \*\*Cubic Farrow Delay Filter:\*\* Fractional delay filter implementation utilizing cubic polynomial interpolation for dynamic delay adjustment.

\- \*\*Low Pass Filter:\*\* Digital FIR low-pass filter design for high-frequency noise attenuation and signal smoothing.

\- \*\*Matched Filter:\*\* Optimal linear filter implementation for maximizing signal-to-noise ratio (SNR) in the presence of additive noise.



\## 🛠️ Tools \& Technologies



\- \*\*HDL:\*\* Verilog

\- \*\*Simulation \& Synthesis:\*\* Xilinx Vivado
